What is happening

  1. Every car runs A* at the start and drives the cheapest route (dashed line).
  2. At t = s an accident closes one road. The traffic-centre agent broadcasts an INCIDENT_ALERT to every car.
  3. Each car checks: is the closed road on my route? If not, it keeps going. If yes, it runs A* again with the road removed and switches to the new route (solid line).
  4. Junction agents choose which road gets green with Max-Pressure (more waiting cars = more pressure); cars stop behind a red light.
